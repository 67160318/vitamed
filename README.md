# vitamed – ร้านขายวิตามินและอาหารเสริม

เว็บแอป static (HTML/CSS/JS) เก็บข้อมูลใน localStorage ของเบราว์เซอร์ จึง deploy บน GitHub Pages ได้

- แอดมินทดลอง: `admin@vitamed.com` / `admin123`
- Deploy: push ขึ้น `main` แล้ว GitHub Actions (`.github/workflows/deploy.yml`) จะ deploy ให้อัตโนมัติ
- ตั้งค่าครั้งแรก: Settings → Pages → Source = **GitHub Actions**
